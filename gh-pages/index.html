Why htmlgen

Everything you need to generate HTML in Go, nothing you don't.

</>

Just Go

No template language to learn. Elements are methods that mirror HTML, and Go's own if/for are the control flow. Full IDE support, type checking, and refactoring tools work out of the box.

ns

Blazing Fast

6–19× faster than html/template. Output streams through a buffer with nothing boxed, so rendering a 100-row table allocates zero bytes.

T

Type-Safe

HTML elements, attributes, and even JavaScript generation are all type-checked at compile time. Catch errors before they reach production, not in your logs.

*

Modern Stack

First-class Datastar and HTMX support. Build reactive web applications without npm, without a JavaScript build pipeline — just Go and a CDN script tag.

See it in action

Real code, real patterns. htmlgen reads like the HTML it generates. 

// Elements stream straight to the io.Writer.
// Containers take (attrs, body); void elements take (attrs).
err := h.Render(os.Stdout, func(b *h.B) {
    b.Html(nil, func(b *h.B) {
        b.Head(nil, func(b *h.B) {
            b.Title(nil, func(b *h.B) { b.Text("My Page") })
        })
        b.Body(nil, func(b *h.B) {
            b.Div(h.Attrs("class", "container"), func(b *h.B) {
                b.H1(nil, func(b *h.B) { b.Text("Hello, World!") })
                b.P(nil, func(b *h.B) { b.Text("Welcome to htmlgen.") })
                b.A(h.Attrs("href", "/about"), func(b *h.B) {
                    b.Text("About")
                })
            })
        })
    })
})
No intermediate tree — bodies run immediately and write as they go. 
// A component is just a function taking *h.B.
func Card(b *h.B, title string, body h.Body) {
    b.Div(h.Attrs("class", "card"), func(b *h.B) {
        b.H2(nil, func(b *h.B) { b.Text(title) })
        body(b)
    })
}

h.Render(w, func(b *h.B) {
    Card(b, "Articles", func(b *h.B) {
        // Native Go control flow — no template DSL.
        b.Ul(nil, func(b *h.B) {
            for _, post := range posts {
                if post.Draft {
                    continue
                }
                b.Li(nil, func(b *h.B) { b.Text(post.Title) })
            }
        })
    })
})
Composition is a plain function call — no wrapper types, no combinators. 
h.Render(os.Stdout, func(b *h.B) {
    b.Html(nil, func(b *h.B) {
        b.Head(nil, func(b *h.B) {
            b.Script(h.Attrs("type", "module",
                "src", "https://cdn.jsdelivr.net/gh/starfederation/datastar@v1.0.2/bundles/datastar.js"), nil)
        })
        b.Body(nil, func(b *h.B) {
            // AttrsOf and .With() collect ds/hx builders into h.Attributes.
            b.Div(h.Attrs("id", "app").With(ds.Signal("count", 0)), func(b *h.B) {
                b.Button(
                    h.AttrsOf(ds.OnClick(ds.SetSignal("count", ds.Raw("$count + 1")))),
                    func(b *h.B) { b.Text("Count: ") },
                )
                b.Span(h.AttrsOf(ds.Text(ds.Raw("$count"))), nil)
            })
        })
    })
})
// → <div id="app" data-signals:count="0"><button data-on:click="($count = $count + 1)">…
Reactive counter with Datastar — no npm, no build step. 
// Type-safe event handlers
attr := js.OnClick(
    js.PreventDefault().Stmt(),
    js.ConsoleLog(js.String("clicked")).Stmt(),
)
// → onclick="event.preventDefault(); console.log(\"clicked\")"

// Promise chains
fetch := js.Fetch(js.String("/api/users")).
    Then(js.ArrowFunc([]string{"r"}, js.Ident("r").Method("json")))
// → fetch("/api/users").then(r => r.json())

// DOM manipulation
handler := js.Handler(
    js.EventTarget().Prop("value").
        Assign(js.EventValue().Method("toUpperCase")),
)
// → event.target.value = event.target.value.toUpperCase()

Quick Start

1

Install

go get github.com/jeffh/htmlgen
2

Write

package main

import (
    "os"

    "github.com/jeffh/htmlgen/h"
)

func main() {
    h.Render(os.Stdout, func(b *h.B) {
        b.Html(nil, func(b *h.B) {
            b.Head(nil, func(b *h.B) {
                b.Title(nil, func(b *h.B) { b.Text("Hello") })
            })
            b.Body(nil, func(b *h.B) {
                b.H1(nil, func(b *h.B) { b.Text("Hello, htmlgen!") })
                b.P(nil, func(b *h.B) { b.Text("Generated with Go.") })
            })
        })
    })
}
3

Run

go run main.go
